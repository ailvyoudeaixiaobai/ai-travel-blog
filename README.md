# 爱旅游的AI小白 · GitHub Pages 发布版

网站源文件位于仓库根目录，图片素材在 `assets/`。

## 发布

1. 在 GitHub 新建公开仓库 `ai-travel-blog`。
2. 上传本目录中的全部文件和 `assets/` 文件夹。
3. 打开仓库 **Settings → Pages**，选择 **Deploy from a branch**、`main` 和 `/(root)`，保存。
4. 发布完成后，网址格式为 `https://你的GitHub用户名.github.io/ai-travel-blog/`。请使用仓库 Pages 设置页显示的实际网址。

后续更新同名文件并提交到 `main`，Pages 会自动重新发布。
